## 一、这是什么 + 为什么值得看（定义、边界、劳动盘子及依据）

### 1.1 定义（大白话）

**P5 = "把软、滑、多层、会变形的东西用手（机械手）操作好"这一类体力活。** 技术上叫**形变物体操作（deformable-object manipulation）+ 接触密集操作（contact-rich manipulation，指手和物体之间有持续、复杂的力接触，不是简单地抓起放下刚性方块）**。这是机器人灵巧度（dexterity，手的精细协调能力）的**最前沿**——一块布、一件衬衫、一颗草莓、一坨面团，它们没有固定形状，抓的时候会滑、会皱、会叠在一起，机器人既要"看懂"当前形状，又要用两只手协调地捏、提、翻、抚平。

**四个具体劳动场景（本包 scope）：**
- **专用作物选择性采摘（specialty-crop selective harvest）：** 草莓、苹果、番茄、葡萄——要判断成熟度、绕开叶子、用不压伤果肉的力道摘下（对应冻结行 W6.6）。
- **商用备餐 / 快餐后厨烹饪（commercial food prep / QSR cooking，QSR = quick-service restaurant 快餐店）：** 组装餐盒、舀取分装、油炸、颠锅、处理面团/肉片等会变形的食材（对应 W6.7）。
- **纺织 / 衣物 / 洗衣（textile / garment / laundry）：** 从烘干机里拿出乱成一团的衣物、抖开、识别、折叠、码放；商用场景是餐巾、毛巾、平织品（flatwork）折叠。
- **酒店客房软物整理（housekeeping soft-goods，铺床/整理床品毛巾）：** 铺床单、套被套、叠毛巾（这是 W10.2 酒店运营的**家政软物切片**，以**叠加层**方式重切进 P5，见下）。

### 1.2 为什么单独立一格（边界 / 与相邻格的关系）

P5 在 P 族里被**刻意从 P1/P4 里剥出来单独立格**，原因只有一个（`v3_physicalai_architecture.md` §5-P5）：**这是整张物理地图上，物理灵巧度唯一"可测量地在动"的一格。** 其它物理格要么已部署（P1 结构化产线）、要么被监管卡住（P3 开放道路 AV）、要么纯粹硬件时间线冻结（P4 非结构化、P6 人体接触护理）。P5 不一样——它有一个**明确的"窄口已破、通用仍锁"（narrow-crossed / general-blocked）**的信号，值得一条专门的观察线，而不是被摊薄在 P1/P4/P6 里看不见。

**"窄口已破"（p0b §C.1，管辖性判断）：** π0 在**已知款式 T 恤折叠**上达到 **>80%** 成功率（双手形变操作的标志性里程碑，靠 flow matching + 长动作块实现）——这是**窄口**。
**"通用仍锁"：** **任意/未见衣物、滑的多层布、新食材的通用形变操作仍未被演示、仍被锁死**；**不存在量产的洗衣机器人**——"缺口是形变操作的内在难度叠加消费级的成本/占地/安全"。物理**泛化在软件上进步了，部署可靠性没有**。

**边界（不与谁重复）：**
- **结构化产线上的食品组装/装配**（工程化工位、固定 SKU、高节拍）→ 属 **P1**（W5.7），不在 P5。P5 是 W6.7 里**接触密集、变形食材处理**的那部分。（注：Chef Robotics 的餐盒组装处在 P1↔P5 的边界偏 P1 一侧，见下文诚实标注。）
- **结构化地面清洁 / 送物机器人 / 前台迎宾机器人**（移动为主、几乎不操作软物）→ 属 **P2**，不是 P5。酒店里能被自动化的恰恰是这块（扫地机），**不是**铺床。
- **非结构化保洁残余（厕所/精细清洁）** → 属 **P4**。
- **酒店预订/前台语音坐席** → 数字格 **W3.6**，不是 P5。
- 因此酒店 W10.2 的 $0.5–0.8T 全额**绝不重新计入** P5——只有"家政软物（铺床/床品/毛巾）"这条**变形-难**的细线以**叠加层**方式盖章进 P5。

### 1.3 劳动盘子（labor TAM）及依据

**P5 分区 `[W]`（可加，各冻结行只数一次）：≈ $1.3T**
- **W6.6 专用作物选择性采摘：≈ $0.4–0.7T**（中值 ~$0.55T；季节性农业工资盘，供给受移民政策约束）。

**叠加层（overlay，非可加，不计入 $1.3T）：**

**依据 / 美国工资锚点（Tier-1，BLS OEWS May 2025，验证 2026-09-16）：**

- 全球盘远大于美国——P5 三个职业都是**发展中国家海量、低工资、发达国家高工资**的典型（p0 地理-人头分解），全球 `[W]` 用冻结的 $1.3T 带。

**关键诚实标注（这盘子怎么读）：** $1.3T 是**名义工资盘**，**不是可寻址市场**。今天 P5 的**捕获 ≈ 0%**（守物理 <1.5% 纪律，且远低于 P1 的 1–1.5% 上限）。这是全图**"盘子巨大、硬件时间线锁死、捕获接近零"**特征第二明显的格（仅次于 P4 的 $5.3T@~0%）。**不要把 $1.3T 当成近期可捕获额来读。**

## 二、这份体力工作到底要做哪些步骤（拆成阶段与步骤，大白话）

四个子场景表面不同，但**底层是同一条形变操作流水线**。先给通用流水线，再把四个场景各自的具体动作对上。

### 2.1 通用形变操作流水线（6 阶段）

| 阶段 | 大白话：人在做什么 | 为什么对机器人难 |
|---|---|---|
| **A. 感知与状态估计** | 看一眼——这是一坨什么？哪件？成熟没？皱在哪、叠了几层？ | 软物没有固定形状，"当前构型"本身要估计；多层布/交叠果实/滑食材极难看清 |
| **B. 接近与选点** | 决定先抓哪个点（衣领？草莓梗？餐盒边？） | 抓取点的选择直接决定成败；未见款式/新果子上选点泛化差 |
| **C. 抓取（含单层分离）** | 伸手捏起来——只捏一层，不带起下面的 | 从一叠里**分出单层**（single-layer separation）是公认硬点，要触觉反馈 |
| **D. 形变操作（核心）** | 双手协调地抖开、翻转、对折、抚平；或把果子拧下、把食材舀匀 | 双手协调 + 持续力控 + 物体在操作中不断变形，动作要实时重规划 |
| **E. 放置 / 完成** | 叠好码齐、装盘摆正、把果子轻放进筐 | 力道过大压伤（草莓/被套）、过小掉落；终态质量可测但难达 |
| **F. 质检与纠错** | 折歪了重折、漏摘了回去补、装错了纠正 | 长任务里错误会累积；端到端**二元完成**（binary end-to-end，全程一次做对）仍是墙 |

### 2.2 四场景的具体动作映射

- **专用作物采摘：** A 判成熟度+定位 → B 选果梗/果柄接近点 → C 绕叶避障、稳住果实 → D 拧/剪/拉离（力道不压伤）→ E 轻放集果箱 → F 漏摘/误摘回补。**难点集中在 A（遮挡下识别成熟果）和 D（不压伤的解离）。**
- **QSR / 备餐：** A 识别食材/餐盒位 → B 选舀取/夹取点 → C 抓起（面团/肉片/生菜会变形黏连）→ D 分装/颠翻/涂抹（份量均匀）→ E 摆盘装盒 → F 份量/摆放纠错。**结构化组装（Chef 式舀装）已接近可做；颠锅/揉面/处理黏滑食材仍难。**
- **纺织/洗衣：** A 从一团里估计有几件、什么款 → B 选衣领/两角 → C **抖开+单层分离**（最难）→ D 双手折叠 → E 码放 → F 折歪重折。**已知款式折叠窄口已破；从乱堆里抓取分离任意衣物仍是通用难点。**
- **酒店铺床：** A 识别床品状态 → B 抓被角/床单角 → C 拎起大幅面软物（king 被套宽达 2.5m，超过任何人形的臂展）→ D 抖平、套被套、四角掖塞 → E 铺展对齐 → F 皱褶纠正。**几乎全程在 D 卡死——大幅面、多层、需要绕床移动的双手协调，2026 年没有产品能做。**

## 三、每一步 AI+机器人现在能不能做（核心表）

**读法：** 区分**「软件/大脑」进步**（VLA 模型、感知、策略）vs**「硬件/身体」瓶颈**（执行器、触觉、双手协调硬件、成本/MTBF）。诚实标注哪些是硬件时间线卡住（非模型问题）。
**能/半能/不能** 指**产线级可靠部署**（≥80% 端到端二元成功、无遥操作兜底、可商用），**不是** demo 或厂商自报 eval。
**厂商自报成功率一律标注（vendor-reported），不当产线可靠性入账**（p0b 纪律：区分 partial-credit / 演示 / 第三方产线）。

| 步骤 | 2025 年底（能力 + 靠哪个模型×硬件） | 2026 年 9 月（+具体产品/VLA/机器人） | 这窗口新解锁？ | 备注：大脑 vs 身体 |
|---|---|---|---|---|
| **A 感知 / 状态估计** | 半能。已知物体/结构化场景可识别；软物多层构型估计弱。靠 Gemini Robotics-ER 1.5、通用 VLM | **半能↑**。Gemini Robotics-ER 1.6（2026，具身推理 SOTA，15 项学术基准）+ π0.6/π0.7 感知链改善；已知款式/已知果子识别好，**未见款式泛化仍掉**（LeHome Challenge 2026：未见短袖/长裤成功率明显下降，纯视觉条件不足以稳健泛化） | **部分（软件）** | **大脑侧进步为主**。感知在"已知集"上够用，通用泛化未破 |

| **QSR 烹饪：颠锅/揉面/黏滑食材（D 变体）** | 不能（通用）/ 半能（组装）。Chef 餐盒组装 pilot；Miso Flippy 挣扎 | **半能（组装）/ 不能（烹饪）**。Chef Robotics 组装 ~15 家食品厂、1 亿份（结构化舀装，偏 P1）；Hyphen 自动化 makeline（Chipotle 试点 350 碗/时）；**通用后厨烹饪仍不能** | 否 | 组装=软件够、身体够（结构化）；烹饪=身体侧未破 |

**一句话总结核心表：** 过去 9 个月的**真实增量全在"大脑/软件"侧，且集中在"已知集折叠"这一个窄口**（Sunday/Dyna/π0.6 的高自报成功率）；**身体/硬件侧**（触觉、双手协调硬件、大幅面负载、成本、MTBF）和**长链条端到端可靠性**没有移动。**通用形变操作、任意衣物分离、铺床、通用烹饪——全部仍"不能"，且是硬件时间线问题（5–15 年），不是再等一个更聪明的模型能解的。** GPT-6 Astra 的增量（推理天花板、成本效率、幻觉下降）对 P5 **零影响**——P5 的门从来不是语言模型 IQ。

## 四、耦合与捕获

**耦合类型（coupling）：Coupled（耦合）。** P5 的定价终局是**按产出/替代人工计价**（RaaS per-unit：每份餐、每亩、每件折叠、每间房），计量的是**工人产出对人工工资**，因此厂商可实现 TAM = **捕获率 × 被替代工资盘**，**绝不 SW+labor 相加**。

**当前捕获（capture today）：≈ 0%**（守住 <1.5% 物理纪律，且远在其下）。
- 全 $1.3T 分区里，**唯一非零**的两条是：(1) Dyna 商用平织品折叠（餐巾/毛巾，实数极小，<< $1.3T 的 0.01%）；(2) Chef 食品组装（~15 家厂、1 亿份，但这是**结构化舀装、偏 P1 一侧**，非形变前沿）。**两者相加对 $1.3T 的捕获率四舍五入到 0%。**
- 采摘 ~1,000 台部署 ≈ ag-robot 资本的 ~1.5%，实现 RaaS ~$30–80M，对 $0.55T 盘子捕获 <0.02%。
- 洗衣/铺床/通用烹饪：**捕获严格为 0**（无量产产品）。

**净效应（net effect）：Mixed，偏 Expansion（扩张）为主 + 一条极薄的 Compression（压缩）窄缝。**
- **为什么偏 Expansion：** 三个职业都是**劳动力短缺/供给受限**场景——农业受移民政策约束招不到人、酒店 2025 年 65–87% 报告用工荒（AHLA）、快餐高流失。短缺环境下企业**采用机器人是去填补招不到的岗，不是裁人**→ 缺口填补、扩张味，displacement 反弹小（低社会阻力）。
- **薄 Compression 窄缝：** 仅在"窄口已破"的两处——商用平织品折叠（Dyna 替代洗衣房折叠工）、结构化食品组装（Chef 替代产线装配工）——有真实但极小的人工替代。

**Conviction（信心）：Low。**（`v3_physicalai_architecture.md` §5-P5 冻结）。理由：真实增量是软件窄口 + 厂商自报 eval，无第三方产线验证、无量产、无 P&L 证据；能力≠捕获，pilot-to-production 鸿沟未过。

**Denominator（分母，不与别处重复计）：**
- 分区 `[W]` = **$1.3T** = W6.6(~$0.55T) + W6.7(~$0.75T)，**各只数一次**。
- W10.2 家政软物 **~$0.1–0.2T** 以**叠加层**盖章，**不计入 $1.3T**。
- **无双计守卫：** 结构化食品线/预制建筑 → P1；非结构化保洁 → P4；地面清洁/送物/迎宾机器人 → P2；酒店语音 → W3.6。P5 只认"接触密集/变形物体操作"这条。SW-TAM（食品机器人 ~$3–4B、采摘机器人报告口径 ~$3.13B、酒店机器人 ~$0.76–3.1B）是 `[$]` 部署花费的领先指标，**绝不并入 `[W]`**。

## 六、HTC 猎场读法

### 6.1 可下注的种子 / A wedge（具体细分 + 为什么护城河不迁移）

**结论先行：P5 的可投层不是形变操作硬件/OEM，而是它下面硬件解耦的数据层（P8）。** 这与 HTC 机器人论点、CyberOrigin（组合锚点）完全一致。

- **首选 wedge — 形变/接触密集的"帧级验证"具身数据（P8，非 P5 硬件）。** 每一家折衣公司都在跑 **teleop-in-loop**：Weave 卖 $8k 机器人却在难衣物上**呼叫人类遥操作员**——本质是一个**数据采集漏斗**；Sunday/Dyna 的高成功率也靠海量遥操作+纠错数据喂出来。形变操作的**绑定约束就是动作配对的传感运动数据**（action-paired sensorimotor data，尤其是接触密集/多层布这种"看不出构型"的场景，仿真难合成、必须真实采集），而 teleop 只有 **~5–50 episodes/小时**——这是**按人和流程扩张、不按芯片扩张**的可投层剖面。**护城河为什么不迁移：** 形变操作的"大脑"（VLA）正在跨本体商品化（π0.7/GR 1.5/Skild），**模型不是护城河**；而**帧级验证的接触密集形变数据集是**——它上游于任何单一 OEM、独立于身体、不被巨头垄断。CyberOrigin 的"verified to the frame"角度正落在这里。
- **次选（窄、需极严纪律）— 窄口已破的商用平织品折叠 RaaS。** Dyna 式"餐巾/毛巾/平织品折叠"在**半工程化工位 + 有界 SKU** 下窄口已破且有经常性 RaaS。可投前提**极严**：必须是**经常性留存收入 + 低 teleop 占比**（否则它是 P8 遥操作生意、不是自主捕获）。护城河在**数据+工作流/RaaS 集成+物理网点关系**，**不在机械臂**（臂会商品化）。

### 6.2 该避开什么（OEM / 硬件资本坑）

- **避开 pre-revenue 的形变操作硬件/人形 OEM 高估值轮：** Sunday **$1.15B**、Dyna **>$600M**、Physical Intelligence **~$11B**——**全部 funding≠deployment，多数近零收入**，靠厂商自报 eval 撑叙事。守 p0b：无量产人形车队、估值不是劳动替代代理。
- **避开消费家用折衣硬件（$8k Weave / <$2k Nori 路径）：** 上一轮 FoldiMate/Laundroid 全灭；teleop 兜底=尚未自主；消费硬件毛利/占地/安全是深坑。
- **避开采摘硬件独立赛道：** 资本密集、季节性、作物专用；John Deere / Oishii 在**收编赢家**（Advanced Farm、Tortuga 已被吃）；仅占 ag 资本 ~1.5%——独立回报效率薄。
- **避开 QSR 门店烹饪机器人：** Miso Flippy 前车；连锁**自建/买断**（Sweetgreen→Wonder $186M、Chipotle 自投 Hyphen、Kernel 自建）挤压独立 RaaS。
- **总纪律：** 别把 $1.3T 名义盘当可寻址；别把厂商 99% 自报当产线可靠；别把 P5 当"再等一个更强模型"就解锁——它是硬件时间线（5–15 年）。

### 6.3 三条带日期的证伪信号（到 2027Q4）

1. **【通用是否真破】到 2027Q4，是否出现**第三方（非厂商自报）**评测显示对*任意/未见*衣物 **且** 新食材、跨新环境的零样本形变操作 ≥80% 端到端二元成功、且有 >100 处产线部署？**
   - 是 → P5 从"窄口"转向"通用开始转化"，重估 net 向 Compression，Conv 上调。
   - 否（仍限已知 SKU / 仅厂商自报 / 仍需 teleop 兜底）→ **P5 维持研究前沿，Conv 保持 Low。**（当前证据：Sunday/Dyna 均 vendor-reported + pilot；Weave 需人类兜底；LG CES 失败 → 尚未破。）

2. **【窄口商用是否成真市场】到 2027Q4，Dyna（或同类）是否披露 >$50M 留存/经常性收入、跨 >100 个商用点位（洗衣房/酒店/健身房）、且 teleop-in-loop 占比 <20%？**
   - 是 → 窄口商用平织品折叠是真自主捕获，那条 wedge 可下注（连同其数据层）。
   - 否 / teleop 占比高 → 它是 **P8 遥操作服务**故事，按数据层而非自主捕获来承保。

3. **【采摘是否形成独立市场】到 2027Q4，专用作物选择性采摘部署车队是否 >5,000 台 / 实现 RaaS >$300M（对比 2026 的 ~1,000 台）？**
   - 是 → 市场真形成，但仍需审 Deere/垂直农场是否已把赢家收编（护城河归现任）。
   - 否（停在 ~2026 水平 / 更多独立被 acqui-hire）→ **确认资本设备消费+现任消化格局，非风投市场。**

4. **【QSR 是否跨过阈值】到 2027Q4，机器人备餐是否实现经常性 RaaS >$100M，**或** ≥2 家 top-10 连锁把机器人 makeline/备餐线标准化进产线？**
   - 是 → 备餐（结构化组装端）成真捕获（候选：Chipotle-Hyphen makeline、Wonder-Infinite Kitchen）——但注意价值可能归**连锁自建**而非独立。
   - 否 / 门店烹饪停滞（Miso 模式）→ 确认"结构化组装可做、通用烹饪 too-early"。
