## PART B — Discipline rule for P4 evidence packs: the ARR Reality Ladder

**Principle:** every dollar entering a track TAM gets a revenue-quality tier *and* a metric-type label *before* it is used. Only Tier-A/B, and only after coupling conversion, sizes a track.

### Step 1 — Tier the evidence (revenue quality)
- **A — Anchor ARR.** Recurring revenue corroborated by **≥2 independent sources, ≥1 primary** (company disclosure/filing, or a methodological primary like Sacra), net of the churn/break-clause test, definition-locked. *Only Tier-A sizes a track directly.* Current A-set = the **verified-8** — and use the corroborated figure, never the high one.
- **B — Run-rate / single-primary.** One primary, or an annualized run-rate (e.g., Claude Code ~$2.5B). Usable with a ±band and a note.
- **C — Bookings / TCV / deal-count / consumption / "agentic work units."** **Not revenue.** Deal counts include free trials (Agentforce ~51% paid). Direction-of-travel only; contributes **0** to TAM.
- **D — Valuation / funding raised.** **Never** a revenue or TAM proxy (Decagon 130×, Sierra 79×, Unitree 200×). A raise is an input cost.
- **E — Report-mill / aggregator / vendor deflection %.** Reject as anchor (P0 Tier-2). x402 $50B, Cursor $4B, Lumilens/Poetic mislabels, vendor "80% deflection."

### Step 2 — Five gates every figure must pass (checklist to paste into each evidence pack)
1. **Metric-type gate.** Explicitly label it: ARR / run-rate / TCV / bookings / deal-count / work-units / valuation / funding / deflection%. Only ARR and run-rate advance.
2. **Definition-lock gate (R5).** Reject if the metric was **redefined** (Agentforce → Slackbot + Headless 360) or if two same-year figures spread **>1.5×** (Cursor $2B vs $4B) — carry the low figure or mark "contested."
3. **Break-clause / churn gate (the 11x test).** Strip ACV/TCV on contracts with exit clauses; use **retained/net** revenue. Churn >~30% or undisclosed → drop one tier. Logo-verify (11x's fake ZoomInfo/Airtable).
4. **Corroboration gate (R1).** >$10B claims need ≥2 independent, ≥1 Tier-1/primary; require **≥2 sweeps from different source types** to agree.
5. **Production gate.** Discount for the pilot-to-production chasm: **MIT 95% zero P&L, S&P 42% abandonment (from 17%), <15% reach production.** A POC is not a deployment. Any "resolution/deflection" figure must be **audited genuine-resolution (35–45%)**, not vendor-claimed (80%).

### Step 3 — Human-behind-the-curtain test (the Builder.ai test)
Ask: *"If the AI were removed tomorrow, would the revenue survive?"* If delivery is offshore labor mimicking AI (Builder.ai's ~700 engineers as "Natasha"), it is **services revenue, not agent ARR** — route it to the Services-Arbitrage overlay, not to a net-new agent line.

### Step 4 — Coupling conversion (non-negotiable, from P0)
A Tier-A/B ARR is **never added** to the labor line. Convert it to implied displaced labor via **observed capture rate** (Sierra ~11%, Intercom Fin ~7%, Decagon ~4–11%, XBOW ~20–40%): **vendor realized TAM = capture-rate × displaced-labor.** The thesis is capture-rate *expansion*, not summing two big numbers. Capture ≠ deflection.

**Name the inflation vector.** Tag each haircut with which of the five it is, because the fix differs: (1) **agent-washing** (humans behind curtain / rebadged RPA — Gartner: ~130 real of thousands); (2) **aggregator error** (Lumilens, Poetic, x402 $50B); (3) **valuation-as-ARR** (Decagon/Sierra/Unitree); (4) **metric redefinition/construction** (Agentforce, run-rate, TCV, work-units, deal counts); (5) **bookings/pilots-as-revenue** (<10% past POC).
